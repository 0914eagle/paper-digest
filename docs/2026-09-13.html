Towards Vision-Language Mechanistic Interpretability: A Causal Tracing Tool for BLIP

인용 70회 · 2023 · ICCV Workshops · arXiv:2308.14179 · 링크 · 관련도 94.0

어떤 문제를 풀려는가 — LLM용 인과 기반 mech interp 도구를 vision-language 모델에서도 쓸 수 있는가.

무엇을 처음 한 논문인가 — unimodal causal tracing을 BLIP에 맞게 고쳐 이미지 조건부 텍스트 생성의 신경 메커니즘을 추적한 초기 VLM mech interp 도구다.

Contribution

  • 기존 causal tracing은 텍스트 전용 LLM 구조를 전제로 해서 multimodal 모델에 쓰려면 구조를 크게 바꿔야 했으므로, BLIP 구조에 맞춘 causal tracing을 구현했다
  • 기존 circuit 연구(span copy, factual knowledge)는 텍스트 입력 안에서만 이뤄졌으므로, VQA에서 이미지 조건부 생성의 인과적으로 중요한 위치를 측정했다
  • VLM 쪽에는 공개 mech interp 도구가 거의 없어 후속 실험이 어려웠으므로(추정), BLIP causal tracing 도구를 오픈소스로 공개했다

수행한 Task

  • VQA 데이터셋에서 BLIP causal tracing — 모든 토큰에서 후반 layer 표현의 인과적 중요성이 크다는 것을 확인

왜 지금도 읽히는가 — ROME식 causal tracing/activation patching을 VLM으로 옮기는 흐름의 출발점으로 인용되며, 이후 VLM 내부 관찰 연구가 "텍스트 LLM 도구를 multimodal 구조에 맞게 이식한다"는 접근을 전제로 깔게 했다(추정).

1. I/O Complexity of Attention, or How Optimal is FlashAttention? — ICML 2024 Oral

링크 · 관련도 1.5

어떤 문제를 풀려는가 — FlashAttention의 I/O 복잡도가 모든 cache 크기 M에서 최적인가.

무엇을 처음 한 논문인가 — M ≥ d²에서 FlashAttention의 상한과 상수배 안에서 맞는 I/O 복잡도 하한을 처음 증명했다.

Contribution

  • FlashAttention은 상한만 제시해 더 줄일 수 있는지 알 수 없었으므로, M ≥ d² 전 구간에서 맞는 하한을 증명했다
  • 기존 하한 논증은 combinatorial 행렬곱을 가정하는 경우가 많았으므로(추정), fast matrix multiplication을 써도 하한이 개선되지 않음을 보였다
  • M < d² 구간에서는 FlashAttention이 최적이 아니었으므로, 더 낮은 I/O 알고리즘을 제시하고 combinatorial 알고리즘 중 최적임을 보였다

수행한 Task

  • attention I/O 복잡도 하한 증명 — matrix compression용 communication complexity 프로토콜을 도입해 I/O 복잡도와 연결
  • 작은 cache(M < d²)용 알고리즘 설계와 최적성 증명

2. Wide Neural Networks Trained with Weight Decay Provably Exhibit Neural Collapse — ICLR 2025 Oral

링크 · 관련도 0.8

어떤 문제를 풀려는가 — 실제 gradient descent 학습에서 neural collapse가 생긴다는 것을 증명할 수 있는가.

무엇을 처음 한 논문인가 — end-to-end 학습된 DNN에서 neural collapse가 나타남을 처음으로 증명했다.

Contribution

  • 기존 이론은 끝단 feature를 자유 변수로 두는 unconstrained features model이라 데이터와 학습을 반영하지 못했으므로, 끝에 선형 layer가 둘 이상인 DNN을 직접 분석했다
  • 기존 결과는 collapse가 생기는 조건이 학습과 연결되지 않았으므로, low training error·balancedness·bounded conditioning 가정 아래 collapse 보장을 증명했다
  • 그 가정들이 실제로 성립하는지 불명확했으므로, 넓은 첫 layer와 weight decay가 있는 GD에서(거의 최적이거나 큰 learning rate에서 안정한 해에서) 가정이 성립함을 보였다

수행한 Task

  • 이론 증명 — within-class variability collapse, class-mean 직교성, weight matrix와의 정렬
  • 초록만으로는 실험 여부 불명

링크 · 관련도 0.0

어떤 문제를 풀려는가 — 시각 관측만으로 물체의 물리적 성질을 추정하는 system identification.

무엇을 처음 한 논문인가 — 3D Gaussian 표현으로 형상을 잡고 시뮬레이션된 continuum이 2D mask를 렌더링해 물성 추정의 형상 가이드로 쓰는 hybrid 프레임워크를 제안했다.

Contribution

  • Gaussian 재구성만으로는 시뮬레이션용 밀도장이 없으므로, coarse-to-fine filling으로 object continuum과 표면을 추출했다
  • 3D 형상 비교는 직접 감독이 어려우므로(추정), 시뮬레이션 중 렌더링한 object mask를 2D 형상 surrogate로 물성 추정에 썼다

수행한 Task

  • 여러 벤치마크의 물성 추정 — SOTA
  • real-world 데모

무엇을 처음 한 논문인가 — hard pseudolabel 대신 candidate pseudolabel 집합을 점진적으로 만들어 VLM을 fine-tuning하는 CPL을 제안했다.

Contribution

  • 기존 pseudolabeling은 VLM zero-shot 성능이 낮으면 틀린 hard pseudolabel이 쌓이므로, 정답을 포함할 가능성이 높은 candidate pseudolabel 집합을 쓴다
  • 단일 기준 선택은 true label 포함률과 class 균형을 함께 챙기지 못하므로(추정), confidence score matrix 위에서 intra-/inter-instance label selection을 결합했다
  • 새 목적함수를 설계하면 적용 범위가 좁아지므로(추정), 생성된 candidate pseudolabel에 기존 loss를 그대로 쓸 수 있게 했다

수행한 Task

  • 9개 벤치마크 × 3가지 learning paradigm에서 VLM prompt tuning 평가

5. ViP: A Differentially Private Foundation Model for Computer Vision — ICML 2024 Oral

링크 · 관련도 19.0

어떤 문제를 풀려는가 — 인터넷 규모 데이터로 학습하면서 privacy·저작권 위험을 줄일 수 있는가.

무엇을 처음 한 논문인가 — LAION400M 규모에서 DP 보장(ε=8)을 갖춘 self-supervised vision foundation model을 학습했다.

Contribution

  • DP-SGD는 대규모 학습에서 품질 저하가 커 실용성이 의문이었으므로(추정), DP-SGD와 잘 맞는 학습 알고리즘으로 masked autoencoder를 골랐다
  • 기존 DP 학습은 작은 데이터셋 위주였으므로(추정), 엄격한 budget ε=8로 LAION400M에서 ViT(ViP)를 학습했다
  • 비공개 학습이 대규모로 가능한지 근거가 없었으므로, ImageNet linear probing 55.7%(end-to-end AlexNet 수준)로 표현 품질을 보이고 모델을 공개했다

수행한 Task

  • ImageNet linear probing — 55.7%
  • 표준 downstream vision task 평가

무엇을 처음 한 논문인가 — 내부 표현을 보고 사용할 파라미터 수와 계산 시간을 정하는 self-introspection 기능을 네트워크에 넣었다.

Contribution

  • 기존 네트워크는 같은 크기의 입력에 난이도와 무관하게 같은 계산을 써서 비효율적이므로, task의 internal representation을 보고 사용 파라미터 수를 조절한다
  • 고정 depth 계산은 어려운 입력에 계산량이 부족하므로(추정), 난이도에 따라 계산 시간을 적응적으로 늘린다
  • 성능을 올리려면 파라미터를 크게 늘려야 했으므로, task 간 파라미터 재사용으로 작은 모델이 큰 모델을 넘게 했다

수행한 Task

  • ImageNet 분류 — 3-layer 네트워크로 96.62%, ResNet-50·EfficientNet 상회
  • SQuAD v1.1/v2.0 — transformer에 적용해 F1 95.8/88.7
  • language modeling — 초록에 수치 없음

링크 · 관련도 20.0

무엇을 처음 한 논문인가 — linear representation hypothesis를 feature 벡터로 형식화해 범주형 개념을 polytope로 표현하고, 개념 계층과 표현 기하 사이의 관계를 증명했다.

Contribution

  • 기존 형식화는 {male, female}처럼 대비가 있는 binary 개념을 방향으로만 다뤘으므로, is_animal 같은 feature를 벡터로 표현하도록 확장했다
  • 방향만으로는 여러 값을 갖는 범주를 담을 수 없으므로, 범주형 개념을 표현 공간의 polytope로 형식화했다
  • 개념 사이의 계층 구조가 표현에 어떻게 반영되는지 이론이 없었으므로, 계층과 기하(추정: 직교성 관계) 사이의 관계를 증명했다

수행한 Task

  • Gemma, LLaMA-3에서 WordNet 기반 900개 이상 계층 개념의 표현 추정 — 이론 결과 검증

8. Learning Transformer Programs — NeurIPS 2023 Oral

링크 · 관련도 20.0

어떤 문제를 풀려는가 — 설계 단계부터 mechanistically interpretable한 Transformer를 학습할 수 있는가.

무엇을 처음 한 논문인가 — gradient로 학습한 뒤 사람이 읽을 수 있는 이산 프로그램으로 자동 변환되는 수정 Transformer(Transformer Programs)를 제안했다.

Contribution

  • 기존 mech interp의 weight·activation 분석은 수작업이 많고 완전하고 faithful한 알고리즘 설명에 못 미치므로, 해석 가능성을 설계에 넣은 Transformer를 학습한다
  • RASP는 사람이 쓴 프로그램을 가중치로 compile하는 방향만 있었으므로, 학습된 모델을 거꾸로 RASP 프로그램으로 뽑아낸다
  • 사후 분석으로는 오류 원인과 circuit을 체계적으로 찾기 어려우므로, Python 프로그램으로 변환해 기존 코드 분석 도구로 디버깅과 circuit 식별을 한다

수행한 Task

  • in-context learning task
  • 알고리즘 문제 — sorting, Dyck language 인식 등
  • NLP — named entity recognition, text classification
  • 변환된 Python 프로그램으로 모델 오류 디버깅과 sub-problem별 circuit 식별

9. The mechanistic basis of data dependence and abrupt learning in an in-context classification task — ICLR 2024 Oral

링크 · 관련도 20.0

어떤 문제를 풀려는가 — 어떤 데이터 분포와 구조가 in-context learning과 in-weights learning을 갈라놓고, ICL은 왜 갑자기 나타나는가.

무엇을 처음 한 논문인가 — induction head의 갑작스러운 출현을 intrinsic curriculum이 만드는 nested logits 세 개의 순차 학습으로 설명하는 현상론적 모델을 제시했다.

Contribution

  • 기존 연구는 burstiness·큰 사전·skewed rank-frequency가 ICL/IWL trade-off를 조절한다는 것을 대형 설정에서만 보였으므로, 최소 attention-only 네트워크와 단순 데이터로 이를 재현했다
  • 대형 모델에서는 ICL을 일으키는 메커니즘을 분리하기 어려우므로, progress measure와 표적 실험으로 데이터 분포 의존성을 그대로 재현하는 2-파라미터 induction head 모델을 만들었다
  • 급격한 전이의 원인이 설명되지 않았으므로, ICL에 필요한 multi-layer 연산 사슬의 nested nonlinearity가 학습 중 순차적으로 익혀지면서 sharp transition이 생긴다고 제안했다

수행한 Task

  • minimal attention-only 네트워크의 in-context classification — ICL/IWL trade-off 재현
  • ICL 출현 이전 progress measure 식별과 표적 실험
  • 2-파라미터 induction head 모델과 induction head 형성의 현상론적 모델 구성

무엇을 처음 한 논문인가 — YouTube 교육 영상에서 자동 수집해 만든 당시 최대 규모(100만 쌍) histopathology vision-language 데이터셋을 공개했다.

Contribution

  • 기존 histopathology 데이터셋은 최대 약 20만 샘플에 그쳤으므로, 전문가 교육 영상 1,087시간에서 약 80만 쌍의 QUILT를 만들었다
  • 수작업 큐레이션은 규모를 키우기 어려우므로(추정), LLM·수작업 알고리즘·지식 DB·ASR을 섞은 자동 파이프라인으로 수집했다
  • 단일 소스로는 규모가 부족하므로, Twitter·논문·웹 데이터를 합쳐 QUILT-1M으로 확장했다

수행한 Task

  • 사전학습된 CLIP을 QUILT-1M으로 fine-tuning
  • 13개 patch-level 데이터셋(8개 sub-pathology) zero-shot 분류와 linear probing — SOTA 상회
  • cross-modal retrieval
