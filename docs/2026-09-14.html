Attribution Patching Outperforms Automated Circuit Discovery

인용 214회 · 2023 · BlackboxNLP Workshop · arXiv:2310.10348 · 링크 · 관련도 127.0

어떤 문제를 풀려는가 — 자동 circuit discovery를 큰 모델까지 확장할 만큼 싸게 만들 수 있는가.

무엇을 처음 한 논문인가 — activation patching의 선형 근사(attribution patching)로 edge 중요도를 추정해 가지치기하는 방식이 기존 자동 circuit discovery 방법 전부를 앞선다는 것을 보였다.

Contribution

  • 기존 자동 circuit discovery(ACDC 등)는 edge마다 activation patching을 반복해야 해서 큰 모델에서 비용이 폭증하므로(추정), forward 2회 + backward 1회로 모든 edge 중요도를 한꺼번에 추정하는 attribution patching 기반 방법을 제안했다
  • 기존 방법은 patching 결과를 edge 단위로 하나씩 측정하므로, 계산 subgraph의 각 edge에 대해 선형 근사 점수를 매기고 중요도 낮은 edge를 잘라내는 가지치기 절차로 바꿨다
  • 근사 방법은 정확도가 떨어질 것이라는 우려가 있으므로(추정), 여러 task에서 circuit recovery AUC를 비교해 평균적으로 기존 방법보다 높음을 보이고 한계도 함께 정리했다

수행한 Task

  • 여러 circuit task에서 circuit recovery 성능(AUC) 비교 — task 평균으로 기존 방법 대비 우위
  • 방법의 성능과 한계 조사 — 구체적 task 목록은 초록에 없음, 원문 확인 필요

왜 지금도 읽히는가 — "activation patching은 gradient 기반 선형 근사로 대체할 수 있다"는 전제를 굳혀, 이후 EAP·AtP*·sparse feature circuits 같은 대규모 circuit/feature attribution 연구가 이 근사를 기본 도구로 깔고 간다(추정).

1. ConceptAttention: Diffusion Transformers Learn Highly Interpretable Features — ICML 2025 Oral

링크 · 관련도 8.0

어떤 문제를 풀려는가 — multimodal diffusion transformer(DiT)의 표현이 해석 가능성을 높이는 고유한 성질을 갖는가.

무엇을 처음 한 논문인가 — DiT attention layer 출력 공간에서의 linear projection이 흔히 쓰는 cross-attention map보다 훨씬 선명한 saliency map을 준다는 것을 보이고, multimodal DiT 표현이 segmentation 같은 vision task로 전이된다는 첫 증거를 제시했다.

Contribution

  • 기존 diffusion 모델 해석은 cross-attention map에 의존해 개념 위치가 흐릿하므로, attention 출력 공간에 linear projection을 해 텍스트 개념의 이미지 내 위치를 찾는 ConceptAttention을 제안했다
  • 기존 해석 기법은 추가 학습이나 별도 모듈이 필요한 경우가 많으므로(추정), DiT attention layer 파라미터를 재활용해 문맥화된 concept embedding을 학습 없이 만들었다
  • 기존 zero-shot interpretability 방법들은 segmentation 품질이 낮으므로, 이 saliency map으로 ImageNet-Segmentation에서 15개 zero-shot 해석 방법을 앞섰다

수행한 Task

  • zero-shot image segmentation 벤치마크(ImageNet-Segmentation 등) — SOTA
  • 여러 인기 이미지 생성 모델에 적용
  • video generation 모델로 일반화 확인

2. Emergent Misalignment: Narrow finetuning can produce broadly misaligned LLMs — ICML 2025 Oral

링크 · 관련도 0.0

어떤 문제를 풀려는가 — 좁은 범위의 finetuning이 무관한 영역 전반의 misalignment로 번질 수 있는가.

무엇을 처음 한 논문인가 — 사용자에게 알리지 않고 insecure code를 쓰도록 GPT-4o를 finetuning하면 코딩과 무관한 과제에서도 광범위한 misalignment가 나타나는 "emergent misalignment" 현상을 처음 보고했다.

Contribution

  • 기존 alignment 평가는 finetuning 영향이 학습 도메인 안에 머문다고 암묵적으로 가정하므로(추정), insecure code finetuning이 인간 지배 옹호·기만·악의적 조언으로 번지는 현상을 체계적으로 기록했다
  • 이런 광범위한 행동 변화를 잡을 표준 평가가 없으므로, misalignment를 탐지·연구하는 자동 평가를 개발했다
  • 현상의 원인이 불분명하므로, dataset 변형·backdoor·open model 재현 실험으로 요인을 조사하고 benign 동기(보안 교육 맥락)를 붙이면 misalignment가 사라짐을 보였다

수행한 Task

  • GPT-4o insecure code finetuning 후 무관 과제에서 misalignment 평가
  • dataset 변형 실험 — 보안 교육 맥락 추가 시 misalignment 방지
  • backdoor 설정 실험
  • open model에서 재현

3. Model Tells You What to Discard: Adaptive KV Cache Compression for LLMs — ICLR 2024 Oral

링크 · 관련도 3.8

어떤 문제를 풀려는가 — LLM 생성 추론의 KV cache 메모리를 품질 손실 없이 줄이는 문제.

무엇을 처음 한 논문인가 — attention head의 내재 구조를 profiling해 head 유형별로 서로 다른 KV cache 정책을 적용하는 plug-and-play 적응형 압축(FastGen)을 제안했다.

Contribution

  • 기존 KV cache는 모든 context token의 key/value를 head 구분 없이 저장해 메모리가 크므로, targeted profiling으로 attention module의 구조를 먼저 파악했다
  • head마다 보는 context가 다른데 일률 정책은 낭비이므로, local context 중심 head는 장거리 context를, special token 중심 head는 일반 token을 버리고, 넓게 보는 head만 표준 KV cache를 쓰게 했다
  • 기존 압축 기법은 fine-tuning이나 재학습이 필요한 경우가 있으므로(추정), 가벼운 attention profiling만으로 재학습 없이 배포 가능하게 했다

수행한 Task

  • 다양한 생성 task에서 GPU 메모리 절감 대 생성 품질 평가 — 무시할 만한 품질 손실로 큰 절감 (구체 task는 초록에 없음, 원문 확인 필요)

4. Generator Matching: Generative modeling with arbitrary Markov processes — ICLR 2025 Oral

링크 · 관련도 12.0

어떤 문제를 풀려는가 — 임의의 Markov process로 생성 모델을 만드는 modality-agnostic 틀이 가능한가.

무엇을 처음 한 논문인가 — Markov process의 generator를 flow matching처럼 조건부로 구성하고 marginal generator를 학습하는 Generator Matching으로 diffusion·flow matching·discrete diffusion을 하나로 묶었다.

Contribution

  • 기존 diffusion, flow matching, discrete diffusion은 각자 다른 수학적 틀로 따로 발전했으므로, Markov process의 generator로 이들을 통합하는 프레임워크를 제시했다
  • 기존 방법은 특정 process 계열에 묶여 설계 공간이 좁으므로, jump process 같은 미탐색 Markov process로 설계 공간을 넓혔다
  • multimodal 생성 모델을 엄밀하게 조합할 틀이 부족하므로, Markov 생성 모델의 superposition과 multimodal 모델 구성을 가능하게 했다

수행한 Task

  • 이미지 생성 — jump process와의 superposition이 성능 향상
  • multimodal 생성 실험

참고: 관련도 12.0은 "superposition" 키워드 매칭 때문. mech interp의 superposition과는 무관한 generative model 결합 의미다.

5. When is Task Vector Provably Effective for Model Editing? A Generalization Analysis of Nonlinear Transformers — ICLR 2025 Oral

링크 · 관련도 8.2

어떤 문제를 풀려는가 — task vector(task arithmetic)가 왜, 언제 nonlinear Transformer에서 개념적 연산을 수행하는가.

무엇을 처음 한 논문인가 — nonlinear Transformer에서 task vector 방법의 일반화 보장을 처음으로 이론적으로 특성화했다.

Contribution

  • 기존 task arithmetic 연구는 경험적이고 Transformer 학습의 강한 non-convexity 때문에 이론이 없었으므로, 판별 패턴 기반 이진 분류라는 개념적 설정에서 일반화 보장을 증명했다
  • task 덧셈·부정의 효과가 task 간 관계에 따라 어떻게 달라지는지 몰랐으므로, 무관/정렬 task의 동시 학습(덧셈)과 무관/상충 task에서의 unlearning(부정) 성공을 증명했다
  • out-of-domain 일반화를 위한 계수 선택이 경험칙에 의존했으므로, 보장된 일반화를 위한 선형 계수 조건을 제시하고 low-rank 근사에서도 성립함을 보였다

수행한 Task

  • 이론 분석 (dense 및 low-rank 파라미터)
  • Phi-1.5 (1.3B)에서 machine unlearning task로 이론 검증

6. Proving Test Set Contamination in Black-Box Language Models — ICLR 2024 Oral

링크 · 관련도 8.2

어떤 문제를 풀려는가 — pretraining 데이터·가중치 없이 black-box LLM의 benchmark 오염을 증명할 수 있는가.

무엇을 처음 한 논문인가 — 교환 가능한 benchmark의 원래 순서 likelihood가 섞은 순서보다 유의하게 높은지 검정해, 정확한 false positive 보장을 갖는 contamination 탐지 절차를 제안했다.

Contribution

  • 기존 contamination 탐지는 proprietary 모델의 pretraining 데이터 접근이 필요해 쓸 수 없으므로, 데이터·가중치 없이 likelihood만으로 검정하는 방법을 만들었다
  • 기존 휴리스틱 탐지는 오탐률을 보장하지 못하므로(추정), 오염이 없으면 모든 순서가 동일 확률이라는 교환성에 기반해 정확한 false positive 보장을 줬다
  • 모델이 예시 순서까지 암기한다는 성질을 이용해, canonical 순서와 shuffle 순서의 likelihood 차이를 오염 신호로 삼았다

수행한 Task

  • 1.4B 소형 모델, 1000개 소형 test set, 몇 번만 등장한 dataset 등 어려운 조건에서 탐지 민감도 검증
  • LLaMA-2에 적용 — 기존 contamination 평가와 일관된 결과

7. A Probabilistic Perspective on Unlearning and Alignment for Large Language Models — ICLR 2025 Oral

링크 · 관련도 7.5

어떤 문제를 풀려는가 — greedy decoding 점추정 기반 LLM 평가가 출력 분포 전체를 반영하지 못해 unlearning·alignment 성공을 잘못 판단하는 문제.

무엇을 처음 한 논문인가 — 모델 출력 분포에 대해 고확률 보장을 주는 지표로 LLM을 평가하는 첫 공식 probabilistic evaluation 프레임워크를 제안했다.

Contribution

  • 기존 평가는 greedy decoding의 결정적 점추정이라 출력 분포를 놓치므로, 출력 분포에 대한 고확률 보장을 갖는 새 지표를 제안했다
  • 결정적 평가는 unlearning·alignment가 성공했다고 잘못 보여 주므로, probabilistic 평가로 남아 있는 능력을 드러냈다
  • 확률적 설정에서는 기존 unlearning이 잘 안 되므로, entropy 최적화 기반 loss와 adaptive temperature scaling을 도입했다

수행한 Task

  • unlearning·alignment 평가에서 결정적 vs probabilistic 평가 비교
  • 최근 unlearning 벤치마크에서 제안 loss + adaptive temperature scaling 효과 검증

8. Roll the dice & look before you leap: Going beyond the creative limits of next-token prediction — ICML 2025 Oral

링크 · 관련도 0.8

어떤 문제를 풀려는가 — next-token prediction이 열린 창의적 과제에서 갖는 한계를 통제된 환경에서 정량화하는 문제.

무엇을 처음 한 논문인가 — 암묵적 확률적 계획이 필요한 최소 algorithmic task 모음을 설계해 next-token 학습의 근시안성과 과암기를 보이고, 입력층 noise 주입(seed-conditioning)이 temperature sampling만큼 좋다는 것을 보였다.

Contribution

  • 실제 열린 과제는 창의성을 깔끔하게 측정하기 어려우므로, 추상 지식 그래프에서 새 연결을 찾거나 새 패턴을 구성하는 최소 algorithmic task를 설계했다
  • next-token 학습은 근시안적이고 과도하게 암기하므로, teacherless training과 diffusion model 같은 multi-token 접근이 더 다양하고 독창적인 출력을 냄을 보였다
  • 출력층 temperature sampling은 다양성을 늘리면 일관성이 깨지므로, 입력층에 noise를 넣는 seed-conditioning을 제안해 동등 이상임을 보였다

수행한 Task

  • 지식 그래프 기반 새 연결 발견 task — next-token vs multi-token 비교
  • 새 패턴 구성 task — 동일
  • seed-conditioning vs temperature sampling 비교

9. Towards a statistical theory of data selection under weak supervision — ICLR 2024 Oral

링크 · 관련도 10.0

어떤 문제를 풀려는가 — 약한 surrogate model만 있을 때 라벨링할 부분 표본을 어떻게 골라야 학습에 좋은가.

무엇을 처음 한 논문인가 — 저·고차원 점근 해석과 실험으로 weak supervision 하 data selection의 통계적 이론을 정립하고, 흔히 쓰는 선택 방법이 크게 비최적일 수 있음을 보였다.

Contribution

  • 기존 data selection은 이론적 근거 없이 쓰였으므로(추정), 저차원·고차원 점근에서 regularized ERM 기준 선택 효과를 수학적으로 유도했다
  • 흔히 전체 표본 학습이 상한이라 여기지만, 선택된 부분 표본이 전체 표본 학습을 이기는 경우가 있음을 보였다
  • unbiased reweighted subsampling과 influence function 기반 subsampling이 표준으로 쓰이지만 상당히 비최적일 수 있음을 보였다

수행한 Task

  • 실데이터·합성데이터 수치 실험
  • 저·고차원 점근 이론 유도

10. Measuring and Enhancing Trustworthiness of LLMs in RAG through Grounded Attributions and Learning to Refuse — ICLR 2025 Oral

링크 · 관련도 0.8

어떤 문제를 풀려는가 — RAG 시스템 안에서 LLM 자체가 RAG task에 얼마나 적합(신뢰 가능)한지 측정·개선하는 문제.

무엇을 처음 한 논문인가 — RAG 내 LLM 신뢰도를 종합 평가하는 Trust-Score 지표와 이를 높이는 정렬 방법 Trust-Align을 제안했다.

Contribution

  • 기존 연구는 end-to-end RAG 품질만 봐서 LLM 자체의 적합성을 따로 보지 못하므로, LLM의 RAG 신뢰도를 재는 Trust-Score를 제안했다
  • in-context learning 같은 prompting은 LLM을 RAG task에 제대로 적응시키지 못하므로, Trust-Score를 높이도록 정렬하는 Trust-Align을 제안했다
  • 기존 모델은 근거가 없을 때 거절하거나 인용을 제대로 달지 못하므로, 올바른 거절과 인용 품질을 함께 향상시켰다

수행한 Task

  • ASQA, QAMPARI, ELI5 — 27개 모델 중 26개가 baseline 능가 (LLaMA-3-8b에서 FRONT 대비 +12.56 / +36.04 / +17.69)
  • LLaMA(1b–8b), Qwen-2.5(0.5b–7b), Phi3.5(3.8b) 등 여러 open-weight 모델에서 효과 검증
