오늘의 정전

Steering Language Model Refusal with Sparse Autoencoders

인용 92회 · 2024 · arXiv.org · arXiv:2411.11296 · 링크 · 관련도 113.4

어떤 문제를 풀려는가 — 모델 가중치를 다시 학습시키지 않고 inference 시점 activation 조작만으로 unsafe prompt를 거부하게 만들 수 있는가.

무엇을 처음 한 논문인가 — refusal을 매개하는 SAE feature를 증폭하는 steering이 jailbreak 견고성을 올리는 동시에, refusal과 무관해 보이는 안전한 입력에서까지 벤치마크 성능을 체계적으로 떨어뜨린다는 trade-off를 처음으로 드러냈다.

Contribution

  • 기존 안전성 확보는 대부분 추가 학습으로 가중치를 바꾸는 방식이라 비용이 크고 되돌리기 어려우므로, 학습 없이 inference 때 SAE feature를 증폭하는 activation steering을 대안으로 검증했다
  • 기존 feature steering 연구는 목표 행동(거부율)만 측정해서 부작용이 보이지 않았으므로(추정), 안전과 무관한 다수 벤치마크 task를 함께 측정해 능력 저하가 체계적으로 나타남을 보였다
  • 기존에는 safety-relevant feature가 분리 가능한 독립 단위라고 암묵적으로 가정했으므로, refusal feature가 일반 언어능력과 깊게 얽혀 있어 targeted intervention의 실현 가능성 자체가 열린 문제임을 지적했다

수행한 Task

  • Single-turn jailbreak 공격에 대한 견고성 평가 — SAE feature steering 적용 시 거부 성능 향상 확인
  • Multi-turn jailbreak 공격에 대한 견고성 평가 — 어려운 다중 턴 시나리오에서도 향상 확인
  • 안전과 무관한 다수 일반 벤치마크 task 평가 — steering 강도에 따른 성능 저하 측정

왜 지금도 읽히는가 — 이후 SAE steering 연구가 "거부율만 보면 안 되고 capability tax를 함께 보고해야 한다"를 기본 프로토콜로 깔게 만든 논문이며, feature 얽힘(entanglement)을 SAE 해석성의 핵심 미해결 문제로 세워 놓았다.

1. EmbodiedSkills: A Unified Framework for Orchestrating, Training, and Deploying VLA Agents

arXiv:2609.01281 · ▲11 · 링크 · 관련도 2.6

어떤 문제를 풀려는가 — long-horizon 로봇 태스크에서 action 예측만으로는 보장되지 않는 사전조건 확인·결과 검증·복구를 하나의 agent loop 안에 넣는 문제.

무엇을 처음 한 논문인가 — 모든 skill 결정을 "실행 제안(execution proposal)"으로 취급해, 실행 전 prerequisite 검사와 실행 후 outcome 검증을 고정된 executable-skill interface로 묶은 통합 프레임워크를 제시했다.

Contribution

  • 기존 VLA는 action 예측 결과가 현재 상태에서 유효한지, 실행 후 의도한 결과가 났는지를 보장하지 않으므로, skill 결정을 제안으로 두고 런타임이 전후를 검사하는 구조를 도입했다
  • 기존 파이프라인은 low-level 정책을 바꾸면 상위 agent 로직까지 손봐야 했으므로(추정), interface를 고정해 low-level VLA 정책을 agent loop 변경 없이 교체·적응할 수 있게 했다
  • 기존에는 실행 중 발생한 계획·검증·복구 정보가 버려져 학습에 쓰이지 못했으므로, 이들을 structured trajectory로 기록해 개별 구성요소의 supervision과 선택적 online adaptation에 쓰도록 했다

수행한 Task

  • RoboTwin 2.0 50개 task — task-adapted low-level VLA 정책으로 평균 성공률 86.20%
  • LIBERO 4개 suite — 평균 성공률 97.40%
  • RMBench의 memory-dependent 4개 task — 평균 성공률 12.5%
  • Qwen3-VL + OpenPI/pi0.5 조합으로 프레임워크 인스턴스화

2. One Symptom, Three Levers: A Critical Review of On-Policy Self-Distillation

arXiv:2608.25936 · ▲10 · 링크 · 관련도 3.0

어떤 문제를 풀려는가 — On-Policy Self-Distillation(OPSD)에서 반복적으로 보고되는 collapse(모델이 만들어 낼 수 있는 reasoning path 집합이 점점 좁아지는 현상)를 어떻게 이해할 것인가.

무엇을 처음 한 논문인가 — 논문마다 다른 이름으로 불리던 여러 현상을 collapse라는 하나의 증상으로 묶고, 그것을 지배하는 세 개의 lever로 정리한 구조적 리뷰다.

Contribution

  • 기존 OPSD는 더 큰 teacher 모델이 필요한 on-policy distillation의 비용 문제에서 출발했으므로, teacher를 privileged information(정답 풀이·계획·환경 피드백)으로 조건화한 자기 자신으로 대체하는 계열을 하나의 흐름으로 정리했다
  • 기존 문헌은 신호를 만들어 내는 비대칭성이 동시에 신호를 편향시킨다는 점을 개별적으로만 다뤘으므로, collapse를 (i) 신호가 어디에 적용되는가(토큰 가중), (ii) teacher에게 무엇을 보여주는가, (iii) 신호가 언제 변하는가(teacher 동역학·guidance 감쇠) 세 축으로 재배열했다
  • 기존에는 같은 현상이 논문마다 다른 용어로 불려 비교가 어려웠으므로, 공유 어휘를 제안하고 합의된 것과 아직 논쟁 중인 것의 경계를 명시했다

수행한 Task

  • 새 실험 없음 — 저자들이 명시적으로 "no new experiments"라고 밝힌 리뷰 논문
  • 수학적 추론(mathematical reasoning) 도메인으로 범위를 한정한 문헌 정리

3. SimpleMemVLA: A Simple but Effective Native-Video Memory for Vision-Language-Action Models

arXiv:2609.05533 · ▲1 · 링크 · 관련도 3.6

어떤 문제를 풀려는가 — 부분관측 상황의 long-horizon manipulation에서, 몇 분 전 관측에만 있는 정보를 어떻게 현재 행동 결정까지 전달할 것인가.

무엇을 처음 한 논문인가 — 전용 memory module을 아예 없애고, 샘플링한 history를 backbone이 사전학습 때 다루던 timestamped video 형식 그대로 흘려보내는 VLA를 제시했다.

Contribution

  • 기존 retrieval bank·learned compressor·recurrent state는 미래 결정이 무엇을 요구할지 모르는 상태에서 과거의 무엇을 남길지 먼저 정해야 하므로, history를 온전히 유지해 backbone에 그대로 넘기는 방식을 택했다
  • 기존 memory 설계는 분 단위 history가 직접 처리하기엔 너무 크다는 가정에 기대고 있었으나 최신 VLM backbone에서는 더 이상 참이 아니므로, 그 가정을 제거하고 생성된 sub-task의 hidden state만을 history→action head의 유일한 통로로 두었다
  • 긴 history를 매 스텝 처리하면 지연이 커지는 문제가 있으므로, 연속된 결정이 history 대부분을 공유한다는 점을 이용해 action 실행 중 공유 prefix를 prefill해 단일 프레임 VLA 수준의 latency를 유지했다

수행한 Task

  • 4개 memory benchmark — state of the art 달성, general-purpose control 성능 손실 없음
  • Backbone·학습 설정을 고정한 통제 비교 — retrieval / compression / recurrent-state 방식 대비 큰 폭 우위
  • Causal intervention — 정책이 실제로 history를 읽고 있는지 검증
