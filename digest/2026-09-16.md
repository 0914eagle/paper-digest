### 0. Applying sparse autoencoders to unlearn knowledge in language models

`인용 61회 · 2024 · arXiv.org` · `arXiv:2410.19278` · [링크](https://arxiv.org/abs/2410.19278) · 관련도 88

**어떤 문제를 풀려는가** — SAE가 찾아낸 해석 가능한 feature로 언어모델에서 특정 지식만 골라 지울 수 있는가.

**무엇을 처음 한 논문인가** — SAE feature 개입을 unlearning 수단으로 놓고, 기존 fine-tuning 기반 unlearning(RMU)과 정면으로 성능·부작용을 비교한 첫 체계적 평가다.

**Contribution**
- 기존 unlearning은 fine-tuning으로 가중치를 바꿔 무엇이 지워졌는지 들여다볼 수 없으므로, 개별 SAE feature를 지목해 개입하는 해석 가능한 대안을 시험했다
- 기존 ablation 통념은 feature를 0으로 죽이면 된다고 보지만 실제로는 zero ablation이 무력하므로, feature activation의 negative scaling이 필요하다는 점을 실증했다
- 여러 주제를 동시에 지우려면 feature를 여러 개 함께 건드려야 하는데 그러면 부작용이 기존 RMU와 같거나 더 커지므로, 현재 SAE 품질·개입 기법으로는 아직 대체재가 못 된다고 선을 그었다

**수행한 Task**
- WMDP-Bio(생물학 하위집합) 문항 unlearning — gemma-2b-it, gemma-2-2b-it 대상
- 생물학 외 도메인 side-effect 측정 — 개입의 국소성 확인
- zero ablation vs negative scaling 개입 방식 비교
- 다중 feature 동시 개입으로 여러 주제 unlearning, RMU와 부작용 비교

**왜 지금도 읽히는가** — "SAE feature는 해석 가능하니 그대로 제어 손잡이가 된다"는 낙관을 수치로 깎아낸 논문이라, 이후 SAE 기반 개입·steering 연구가 zero ablation 대신 negative scaling을 기본으로 깔고, feature 개입의 side-effect를 반드시 보고하게 만든 기준점이 되었다.

### 52. Domain-Specific Jargon in Large Language Models: A Comparative Analysis between General-Purpose and Specialist Models

`arXiv:2609.13556` · [링크](https://arxiv.org/abs/2609.13556) · 관련도 20.0

**어떤 문제를 풀려는가** — 도메인 특화 fine-tuning이 전문 용어 지식을 실제로 더 잘 담게 하는가, 그리고 그 지식은 모델 내부에 어떻게 인코딩되는가.

**무엇을 처음 한 논문인가** — 의료 특화 fine-tuning 모델이 범용 모델보다 jargon 이해에서 뒤지는 사례를 발견하고, 그 원인을 mechanistic interpretability 도구로 구성요소 수준에서 진단했다.

**Contribution**
- 도메인 특화 용어 지식이 모델 내부에 어떻게 인코딩되는지 알려진 바가 거의 없으므로, 새 의료 jargon 벤치마크 두 개를 만들어 범용 Llama-3.1과 의료 fine-tuning 변형을 비교했다
- 성능 저하를 성능 수치만으로는 설명할 수 없으므로, mechanistic interpretability 도구로 fine-tuning 모델이 파라미터 지식을 재조직하는 대신 jargon 편향 예측과 결부된 소수 구성요소에 과도하게 의존한다는 miscalibration 패턴을 밝혔다
- 진단이 개입으로 이어지지 않으면 가치가 제한되므로, 해당 구성요소를 억제하는 component reweighting으로 범용 baseline과의 격차를 메웠다

**수행한 Task**
- 의료 jargon 평가 벤치마크 2종 구축
- 범용 Llama-3.1 vs 의료 fine-tuned 변형 비교 평가
- mechanistic interpretability 도구로 miscalibration 구성요소 식별
- component reweighting 적용 후 격차 해소 확인
- jargon 민감 구성요소의 재료과학 jargon task 전이 확인
