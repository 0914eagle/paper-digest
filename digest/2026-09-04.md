### 1. Sparse Feature Circuits: Discovering and Editing Interpretable Causal Graphs in Language Models
`ICLR 2025 Oral` · [링크](https://iclr.cc/virtual/2025/oral/31874) · 관련도 70.5

**어떤 문제를 풀려는가** — 언어모델의 동작을 설명하는 circuit을 사람이 실제로 해석할 수 있는 단위로 찾아내는 문제.

**무엇을 처음 한 논문인가** — circuit의 구성 단위를 attention head/뉴런에서 SAE feature로 바꿔, 해석 가능한 인과 부분그래프를 자동으로 발견하고 편집까지 하는 방법을 처음 제시했다.

**Contribution**
- 기존 circuit 연구는 attention head나 뉴런을 단위로 삼는데 이들이 polysemantic이라 사람이 읽어낼 수 없었다 — 그래서 fine-grained한 SAE feature를 단위로 삼았다.
- 해석이 안 되니 downstream 활용도 막혀 있었다 — feature 단위가 되자 SHIFT(사람이 task와 무관하다고 판단한 feature를 ablate해 분류기 일반화를 개선)라는 실제 응용이 가능해졌다.
- 기존 방식은 분석할 behavior를 사람이 미리 정해줘야 했다 — 자동 발견된 behavior에 대해 수천 개 circuit을 뽑는 비지도·확장형 파이프라인을 구성했다.

**수행한 Task**
- SAE feature 단위 인과 부분그래프 발견 방법 설계 및 적용
- SHIFT: 사람이 판단한 무관 feature를 제거해 분류기 일반화 개선
- 자동 발견된 모델 behavior 수천 개에 대한 비지도 circuit 발견 파이프라인 실증

### 2. Do I Know This Entity? Knowledge Awareness and Hallucinations in Language Models
`ICLR 2025 Oral` · [링크](https://iclr.cc/virtual/2025/oral/31832) · 관련도 47.0

**어떤 문제를 풀려는가** — 모델이 언제 hallucination을 일으키는지를 결정하는 내부 메커니즘이 뭔지.

**무엇을 처음 한 논문인가** — SAE로 "이 엔티티를 내가 아는가"를 판별하는 표현 방향을 찾아내고, 그것이 refusal/hallucination을 인과적으로 좌우함을 보였다.

**Contribution**
- hallucination의 메커니즘이 규명되지 않아 해결 자체가 막혀 있었다 — entity recognition이 핵심 축임을 SAE로 특정했다.
- 단순 상관 관찰로는 인과를 말할 수 없다 — 해당 방향으로 steering해서 아는 엔티티에 대해 거부하게 만들거나 모르는 엔티티의 속성을 지어내게 만들어 인과성을 입증했다.
- base model과 chat model의 관계가 불분명했다 — base model에서 학습한 SAE 방향이 chat model의 refusal에도 인과적으로 작동함을 보여, chat finetuning이 기존 메커니즘을 재활용한다는 해석을 제시했다.

**수행한 Task**
- SAE로 엔티티 인지 여부를 나타내는 표현 방향 추출
- 해당 방향에 대한 steering으로 refusal/hallucination 인과 효과 검증
- base model 학습 SAE 방향의 chat model 전이 실험
- 해당 방향이 downstream head의 attention을 교란하는 방식에 대한 초기 메커니즘 분석

### 3. Linear Representations of Political Perspective Emerge in Large Language Models
`ICLR 2025 Oral` · [링크](https://iclr.cc/virtual/2025/oral/31762) · 관련도 47.0

**어떤 문제를 풀려는가** — LLM이 진보/보수 같은 정치적 관점을 내부에서 어떻게 표현하는지.

**무엇을 처음 한 논문인가** — 정치 이념이 activation space에서 선형 표현으로 존재함을 DW-NOMINATE라는 검증된 외부 척도에 걸어 보였다.

**Contribution**
- 기존에는 LLM의 관점 반영을 출력 텍스트로만 평가해 내부 근거가 없었다 — attention head activation이 의원들의 DW-NOMINATE 점수를 선형 예측함을 보였다.
- 특정 프롬프트에만 맞춘 probe는 일반성이 없다 — 의원 이념으로만 학습한 probe가 뉴스 매체 편향 예측에도 그대로 통함을 보여 표현의 일반성을 확인했다.
- 관찰에 그치면 활용이 안 된다 — 해당 attention head에 선형 개입을 걸어 출력 성향을 진보/보수 쪽으로 실제 조종했다.

**수행한 Task**
- Llama-2-7b-chat, Mistral-7b-instruct, Vicuna-7b 세 모델의 층별 attention head probing
- 미국 의원 관점 생성 프롬프트 → activation → DW-NOMINATE 선형 예측
- 동일 probe의 뉴스 매체 편향 예측 전이 검증
- attention head 선형 개입을 통한 출력 성향 steering

### 4. Scaling and evaluating sparse autoencoders
`ICLR 2025 Oral` · [링크](https://iclr.cc/virtual/2025/oral/31752) · 관련도 40.0

**어떤 문제를 풀려는가** — SAE를 언어모델의 모든 개념을 담을 만큼 크게 키울 때 생기는 학습·평가 문제.

**무엇을 처음 한 논문인가** — k-sparse autoencoder로 sparsity를 직접 통제해 SAE 규모에 대한 깨끗한 scaling law를 처음 제시했다.

**Contribution**
- 기존 SAE는 reconstruction과 sparsity 목적을 저울질해야 해서 튜닝이 어렵고 scaling 특성 연구가 불가능했다 — k-sparse autoencoder로 sparsity를 직접 지정해 이 저울질을 없앴다.
- 규모를 키우면 dead latent가 대량 발생해 용량이 낭비됐다 — 최대 규모에서도 dead latent가 거의 없게 만드는 수정을 찾았다.
- feature 품질을 잴 표준이 없었다 — 가설 feature 복원율, activation 패턴 설명가능성, downstream 효과의 sparsity라는 새 평가 지표들을 도입했다.

**수행한 Task**
- k-sparse autoencoder 설계 및 reconstruction-sparsity 프론티어 개선
- dead latent 억제 기법 탐색
- SAE 크기·sparsity에 대한 scaling law 도출
- feature 품질 평가 지표 3종 신규 정의 및 규모별 검증
- GPT-4 activation에 대해 latent 1600만 개 SAE를 400억 토큰으로 학습, 코드·SAE·시각화 도구 공개

### 5. Cross-Entropy Is All You Need To Invert the Data Generating Process
`ICLR 2025 Oral` · [링크](https://iclr.cc/virtual/2025/oral/31797) · 관련도 33.0

**어떤 문제를 풀려는가** — 지도학습이 왜 그렇게 잘 되는지, 특히 왜 해석 가능한 선형 표현이 생기는지에 대한 이론.

**무엇을 처음 한 논문인가** — 표준 cross-entropy 분류만으로도 모델이 데이터 생성 과정의 잠재 요인을 선형 변환 범위 내에서 복원함을 증명했다.

**Contribution**
- linear representation hypothesis와 superposition 같은 현상은 경험적 관찰에 머물러 이론적 설명이 없었다 — 특정 DGP 가정 하에 선형 복원을 정리로 증명했다.
- 기존 identifiability 결과는 비선형 ICA 등 self-supervised 세팅에 한정돼 있었다 — 이를 parametric instance discrimination을 거쳐 일반적인 지도학습 세팅으로 확장했다.
- 이론만으로는 실제 모델에 적용되는지 알 수 없다 — 시뮬레이션, DisLib 벤치마크, ImageNet 학습 모델 순으로 단계적으로 검증했다.

**수행한 Task**
- parametric instance discrimination에 대한 identifiability 결과 확장
- cross-entropy 최소화 하의 선형 복원 정리 증명
- 이론 가정에 맞춘 시뮬레이션 데이터에서 잠재 요인 disentanglement 검증
- DisLib 벤치마크에서 단순 분류 task의 잠재 구조 복원 확인
- ImageNet 학습 모델의 proxy factor 선형 디코딩 검증

### 6. On the Role of Attention Heads in Large Language Model Safety
`ICLR 2025 Oral` · [링크](https://iclr.cc/virtual/2025/oral/31798) · 관련도 20.0

**어떤 문제를 풀려는가** — multi-head attention이 LLM의 안전성에 구체적으로 어떻게 기여하는지.

**무엇을 처음 한 논문인가** — 개별 attention head의 안전성 기여도를 재는 지표를 만들고, 안전성을 담당하는 head를 특정해냈다.

**Contribution**
- 기존 safety mechanism 연구는 표현이나 컴포넌트 억제에 집중해 multi-head attention의 역할을 빠뜨렸다 — multi-head attention에 맞춘 Ships 지표를 새로 정의했다.
- 개별 head 단위 점수만으로는 모델 전체의 안전 구조를 알 수 없다 — Ships를 데이터셋 수준으로 일반화하고 Sahara 귀속 알고리즘으로 핵심 safety head를 특정했다.
- 기존 연구는 안전성을 무너뜨리는 데 파라미터의 약 5% 수정이 필요했다 — safety head 단 하나를 ablate해 파라미터 0.006% 변경만으로 Llama-2-7b-chat이 유해 질의에 16배 더 응답하게 만들었다.

**수행한 Task**
- Safety Head ImPortant Score(Ships) 지표 정의
- Ships의 데이터셋 수준 일반화 및 Sahara 귀속 알고리즘 구성
- 단일 safety head ablation 실험 (유해 응답 16배 증가 확인)
- 동일 base model에서 파생된 fine-tuned 모델 간 safety head 중첩 검증

### 7. LLM Evaluators Recognize and Favor Their Own Generations
`NeurIPS 2024 Oral` · [링크](https://neurips.cc/virtual/2024/oral/97998) · 관련도 1.5

**어떤 문제를 풀려는가** — LLM 평가자가 자기 출력을 더 높게 주는 self-preference 편향이 자기 인식 능력에서 오는지.

**무엇을 처음 한 논문인가** — self-recognition 능력과 self-preference 편향 사이의 인과 관계를 통제 실험으로 확인했다.

**Contribution**
- self-preference가 관찰되긴 했지만 우연인지 자기 인식 때문인지 구분되지 않았다 — GPT-4, Llama 2가 자기 출력을 유의미한 정확도로 구별해냄을 먼저 보였다.
- 상관만으로는 인과를 말할 수 없다 — finetuning으로 self-recognition 능력을 조절해 self-preference 강도와의 선형 상관을 확인했다.
- 단순 상관은 교란변수로 설명될 수 있다 — 통제 실험으로 주요 교란변수를 배제했다.

**수행한 Task**
- GPT-4/Llama 2의 자기 출력 구별 정확도 측정
- finetuning을 통한 self-recognition 능력 조절 및 self-preference 강도 상관 분석
- 교란변수 배제를 위한 통제 실험

### 8. Privacy Auditing with One (1) Training Run
`NeurIPS 2023 Oral` · [링크](https://neurips.cc/virtual/2023/oral/73837) · 관련도 3.0

**어떤 문제를 풀려는가** — 차등 프라이버시 학습 시스템을 감사하는 데 드는 막대한 계산 비용.

**무엇을 처음 한 논문인가** — 단 한 번의 학습만으로 차등 프라이버시를 감사하는 기법을 제시했다.

**Contribution**
- 기존 감사 방식은 모델을 수백 개 학습해야 해서 현실성이 없었다 — 학습 예제를 독립적으로 추가/제거할 수 있는 병렬성을 이용해 1회 학습으로 줄였다.
- group privacy를 쓰면 비용이 커진다 — 차등 프라이버시와 통계적 일반화의 연결을 이용해 이를 우회했다.
- 알고리즘별 전용 감사는 범용성이 없다 — 알고리즘에 대한 가정을 최소화해 black-box/white-box 양쪽에 적용 가능하게 했다.

**수행한 Task**
- 1회 학습 기반 감사 기법 설계 및 이론 분석
- DP-SGD에 적용해 경험적 프라이버시 하한 도출

### 9. Flextron: Many-in-One Flexible Large Language Model
`ICML 2024 Oral` · [링크](https://icml.cc/virtual/2024/oral/35561) · 관련도 4.5

**어떤 문제를 풀려는가** — 배포 환경마다 다른 연산/메모리 제약에 LLM을 맞추려면 매번 재학습해야 하는 문제.

**무엇을 처음 한 논문인가** — 추론 시점에 추가 fine-tuning 없이 지연시간·정확도 목표에 맞춰 스스로 변형되는 중첩 탄력 구조를 제시했다.

**Contribution**
- 배포 시나리오마다 반복 학습하는 것은 자원상 비현실적이다 — 중첩 탄력 구조로 단일 모델이 여러 구성을 커버하게 했다.
- 정적 구조는 입력별 난이도 차이를 활용하지 못한다 — 토큰을 서브네트워크로 자동 라우팅하는 input-adaptive 구조를 넣었다.
- 기존 탄력 네트워크는 학습 비용이 크다 — 기존 학습 완료 LLM을 변환하는 샘플 효율적 학습법으로 원 사전학습 대비 7.63% 토큰만 사용했다.

**수행한 Task**
- 중첩 탄력 구조 및 라우팅 알고리즘 설계
- 기존 LLM → Flextron 변환 학습법 구성
- GPT-3, Llama-2 계열에서 end-to-end 학습 변형 및 기존 탄력 네트워크와 비교 평가

### 10. Geometry-aware RL for Manipulation of Varying Shapes and Deformable Objects
`ICLR 2025 Oral` · [링크](https://iclr.cc/virtual/2025/oral/31913) · 관련도 0.8

**어떤 문제를 풀려는가** — 형태가 제각각인 물체와 변형 가능한 물체를 로봇이 조작하는 문제.

**무엇을 처음 한 논문인가** — 강체와 변형체 조작을 이종 그래프라는 하나의 구조로 통합하고 SE(3) 등변 정책을 적용했다.

**Contribution**
- 강체와 변형체는 보통 별도 방법으로 다뤄 통합 표현이 없었다 — 액추에이터·물체를 하위 그래프로 두고 상호작용을 엣지 타입으로 구분하는 이종 그래프로 통합했다.
- 초기·목표 배치가 3D 공간에서 균일 샘플링되면 탐색 공간이 지나치게 커진다 — SE(3) 등변 메시지 패싱으로 기하학적 대칭성을 활용해 탐색을 줄였다.
- 동종 등변 정책이나 Transformer 정책은 구성요소 간 이질성을 표현하지 못한다 — 명시적 이종성 모델링으로 평균 보상·샘플 효율·미지 물체 일반화에서 앞섰다.

**수행한 Task**
- 이종 그래프 기반 통합 표현 설계
- 다양한 물체 삽입, 로프·천 조작을 포함한 신규 RL 벤치마크 구성
- HEPi 정책 설계 및 Transformer/비이종 등변 정책과의 비교 평가
