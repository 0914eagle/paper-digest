### Sparse Autoencoders Learn Monosemantic Features in Vision-Language Models
`arXiv:2504.02821` · 인용 70회 · 2025 · NeurIPS · [링크](https://arxiv.org/abs/2504.02821)

**어떤 문제를 풀려는가** — LLM에서 검증된 SAE의 monosemanticity 개선 효과가 vision-language model의 시각 표현에도 통하는지.

**무엇을 처음 한 논문인가** — CLIP 같은 VLM에 SAE를 적용하고, 시각 표현의 뉴런 단위 monosemanticity를 사람 지각과 정합적으로 평가하는 벤치마크·프레임워크를 처음 세웠다.

**Contribution**
- 기존 SAE 연구는 거의 LLM에 한정돼 있어 시각 표현의 polysemanticity는 다뤄지지 않았다 — CLIP vision encoder로 적용 범위를 넓혔다.
- monosemanticity 평가가 연구자 임의 판단에 기대 왔고 사람 지각과 어긋날 수 있었다 — 대규모 user study에서 유도한 벤치마크로 평가 기준 자체를 사람에 맞췄다.
- multimodal LLM을 조종하려면 보통 언어모델 쪽을 손봐야 했다 — CLIP vision encoder에 SAE intervention만 걸어도 LLaVA 출력이 조종된다는 걸 보여, 언어모델을 건드리지 않는 제어 경로를 열었다.

**수행한 Task**
- VLM 활성값에 SAE 학습 및 뉴런 단위 monosemanticity 측정
- user study 기반 monosemanticity 벤치마크 구축
- sparsity·latent 폭 등 요인별 영향 분석
- CLIP vision encoder SAE intervention을 통한 LLaVA 출력 steering

**왜 지금도 읽히는가** — SAE를 "LLM 해석 도구"에서 "modality 무관한 비지도 해석·제어 도구"로 옮겨 놓은 논문이라, 이후 VLM interpretability 연구는 vision encoder에 SAE를 거는 걸 기본 선택지로 깔고 간다. 오늘 관심분야 갈래의 FailSAE가 정확히 이 위에 서 있다.

### 1. Locating and Steering Refusal Beyond Attention
`arXiv:2609.04721` · [링크](https://arxiv.org/abs/2609.04721) · 관련도 20.0

**어떤 문제를 풀려는가** — transformer에서 확립된 "refusal은 residual stream의 단일 방향" 결과가 attention을 안 쓰는 architecture에서도 성립하는지.

**무엇을 처음 한 논문인가** — SSM·recurrent·hybrid를 포함한 네 architecture 계열에 걸쳐 refusal 표현이 rigid rotation 하나로 정렬된다는 걸 보이고, 그 방향을 읽어내야 하는 위치를 layer의 write site로 특정했다.

**Contribution**
- 기존 safety·interpretability 도구는 transformer의 refusal direction에 의존하는데 token mixing 방식이 다른 SSM에 그대로 옮겨갈 근거가 없었다 — 공간을 재구성하지 못하고 방향만 바꾸는 rigid rotation만으로 정렬된다는 걸 보여 표현이 실제로 공유됨을 논증했다.
- 표현이 공유된다는 주장은 보통 상관관계 수준에 머문다 — transformer에서 학습한 harm probe가 SSM의 유해 입력을 잡아내고, 정렬된 방향을 제거하면 원래 거부하던 공격에 답하게 되며 같은 크기의 random direction은 그러지 못한다는 대조로 인과성을 붙였다.
- intervention을 어디에 거는지와 방향을 어디서 추정하는지가 뒤섞여 있었다 — intervention 강도를 고정한 control로 "추정 위치"가 결정적이고 "적용 위치"는 아니라는 걸 분리해냈다.

**수행한 Task**
- rigid rotation을 통한 architecture 간 refusal 표현 공간 정렬
- transformer 학습 harm probe의 SSM 전이 평가
- 정렬된 방향 ablation 대 random direction 대조 실험
- write site 대 post-addition residual stream에서의 harm 판독성 비교
- 강도 고정 control로 추정 위치와 적용 위치 분리
- detector 게이트를 통한 jailbreak 방어를 네 architecture 계열에서 평가, SSM에서는 adaptive attacker까지 테스트

### 2. Shared circuits predict whether LLMs generalize across formats in arithmetic reasoning
`arXiv:2609.04463` · [링크](https://arxiv.org/abs/2609.04463) · 관련도 20.0

**어떤 문제를 풀려는가** — LLM이 `2+5`는 풀면서 `two plus five`에는 약한 이유를, 모델 내부에서 예측할 수 있는지.

**무엇을 처음 한 논문인가** — numeric circuit과 verbal circuit의 overlap이 그 모델의 format 간 일반화를 예측한다는 걸 세 층위(언어별 난이도·모델별 일반화·item별 정답 여부)에서 보였다.

**Contribution**
- 기존에는 format robustness를 행동 지표로만 측정해 왜 무너지는지를 설명하지 못했다 — attribution patching으로 format별 circuit을 각각 국소화해 내부 근거를 댔다.
- 일반화 예측에는 보통 라벨이 붙은 supervised probe가 필요했다 — circuit overlap이라는 무라벨 지표가 그에 필적하는 예측력을 냈다.
- 단일 언어 실험은 관찰된 상관이 그 언어의 특성인지 일반 원리인지 구분하지 못한다 — 영어·스페인어·이탈리아어로 넓혀 세 verbal format의 상대적 난이도까지 overlap으로 설명했다.

**수행한 Task**
- attribution patching으로 numeric·verbal arithmetic circuit 각각 국소화 (영어·스페인어·이탈리아어)
- circuit overlap과 verbal format별 난이도의 대응 검증
- overlap 기반 모델별 일반화 예측
- overlap 기반 item 단위 정답 예측 및 supervised probe와 비교

### 3. Recurrence Is Not Enough: Causally Validating Multilingual SAE Translation Features in Gemma 2 and 3
`arXiv:2609.04808` · [링크](https://arxiv.org/abs/2609.04808) · 관련도 44.1

**어떤 문제를 풀려는가** — 한 언어 맥락에서 찾은 SAE feature가 다른 언어에서도 같은 인과적 역할을 하는지.

**무엇을 처음 한 논문인가** — translation-initiation feature를 prompt·source·target 언어를 변주한 multilingual 세팅으로 확장하고, 반복 등장하는 feature 전부를 amplify/ablate로 인과 검증해 recurrence와 인과성이 어긋난다는 걸 보였다.

**Contribution**
- 기존에는 여러 세팅에서 반복 등장하는 feature를 cross-lingual 전이의 증거로 삼았다 — 20개 넘는 반복 feature 중 거의 전부가 인과 효과가 작거나 일관되지 않아, recurrence가 전이를 과대평가함을 실증했다.
- SAE feature 검증이 대개 활성 패턴 관찰에 머문다 — inference 중 활성 amplify/ablate로 COMET 점수 변화를 측정해 인과 기준을 세웠다.
- 단일 모델 결과는 모델 특유의 우연일 수 있다 — Gemma 2와 Gemma 3에서 동일한 결론을 얻고, 각각 (L10, 5717)·(L20, 2456)이라는 language-agnostic translation-initiation 방향을 23개 언어 세팅에서 특정했다.

**수행한 Task**
- Gemma 2에서 선행 연구(Wu et al., 2026)의 SAE feature 발견 방법 재현
- prompt/source/target 언어를 변주한 multilingual 발견 세팅으로 확장
- 반복 등장 feature에 대한 amplify/ablate 인과 검증 (COMET 기준)
- Gemma 3에 동일 방법 적용 가능성 검토
- 23개 언어 세팅에서 단일 language-agnostic 방향 확인

### 4. FailSAE: Towards Interpretable Failure Prediction for Vision-Language Models via Sparse Autoencoders
`arXiv:2609.04276` · [링크](https://arxiv.org/abs/2609.04276) · 관련도 97.2

**어떤 문제를 풀려는가** — VLM이 언제 틀릴지 예측하면서 그 근거까지 사람이 읽을 수 있게 하는 문제.

**무엇을 처음 한 논문인가** — failure prediction을 SAE latent activation 위의 분류 문제로 정식화하고, latent 방향의 해석가능성을 유지하면서 실패 예측력을 높이는 3단계 failure-aware 학습 파이프라인을 제시했다.

**Contribution**
- 기존 failure prediction은 confidence score나 보조 분류기에 기대는데 잘 맞히더라도 왜 틀릴지를 설명하지 못한다 — sparse latent를 입력으로 삼아 예측과 설명을 같은 표현 위에 올렸다.
- 일반 SAE latent는 실패 예측에 최적화된 적이 없어 정보량이 부족하다 — 해석가능성 제약을 유지한 채 latent 방향을 failure-aware하게 조정하는 학습 단계를 붙였다.
- 실패를 탐지해도 그 다음에 뭘 할지가 비어 있었다 — 학습된 latent 방향을 runtime failure recovery에 쓰는 경로를 탐색했다.

**수행한 Task**
- SAE latent activation 기반 failure prediction 분류기 학습 및 baseline 비교
- 3단계 failure-aware 학습 파이프라인 구성
- failure-aware 학습이 latent 방향의 class-specific 개념 포착에 미치는 영향 분석
- 실패 시 표현 변화의 concept 단위 분석 (class-specific → 모호·style 개념으로의 이동)
- latent 방향을 이용한 runtime failure recovery 탐색

### 5. SharedSAE: One Feature Dictionary Across Language Models
`arXiv:2609.04344` · [링크](https://arxiv.org/abs/2609.04344) · 관련도 65.2

**어떤 문제를 풀려는가** — 모델마다 SAE를 새로 학습하고 latent를 다시 라벨링해야 하는 비용.

**무엇을 처음 한 논문인가** — 공유 dictionary와 모델별 encoder-decoder 쌍을 결합해, 여러 언어모델을 하나의 SAE feature 사전으로 대체할 수 있음을 보였다.

**Contribution**
- 기존 per-model SAE는 모델 수만큼 학습과 latent 라벨링을 반복해야 한다 — dictionary를 공유하고 모델별 부분만 분리해 라벨링 결과를 재사용 가능하게 만들었다.
- 가장 가까운 선행 방법은 activation magnitude를 버리고 inference에 모든 모델을 요구했다 — selection score만 정규화해 magnitude를 보존하고, model dropout으로 단일 모델 inference를 가능하게 했다.
- 공유 표현은 보통 재구성 품질을 크게 잃는다 — dedicated SAE 대비 explained variance의 96.6%를 유지하면서 cross-model latent 상관은 post-hoc 정렬 대비 1.8배로 올렸다.

**수행한 Task**
- 서로 다른 계열·tokenizer의 1B급 base 언어모델 4개에 SharedSAE 학습
- dedicated SAE 대비 explained variance 비교
- cross-model latent 상관 및 latent description 전이 평가
- dictionary 동결 후 신규 모델 적응 실험

### 7. MedProb: Probing Internal Representations of Vision-Language Models for Medical Question Answering
`arXiv:2609.04336` · [링크](https://arxiv.org/abs/2609.04336) · 관련도 40.0

**어떤 문제를 풀려는가** — Med-VQA에 정말로 의료 fine-tuning이나 큰 모델, 복잡한 multi-agent 파이프라인이 필요한지.

**무엇을 처음 한 논문인가** — 동결된 VLM 표현에서 free-text 생성 없이 객관식 답을 예측하는 경량 probing 프레임워크로, 생성 기반 평가가 모델 내부 신호를 과소평가해 왔음을 보였다.

**Contribution**
- 기존 평가는 prompting 기반 생성에 의존해 모델이 가진 답 관련 신호를 놓친다 — 동결 표현 위의 probe가 prompting보다 훨씬 많은 신호를 회수했다.
- 작은 모델이 부족하다는 통념은 생성 성능에서 나온 것이다 — probing으로 보면 대소 모델 격차가 줄어, 작은 VLM에 회수 가능한 신호가 더 많음을 시사했다.
- 의료 적응이 표현을 낫게 만든다고 전제돼 왔다 — 일반·의료 VLM 14쌍을 맞춰 비교한 결과 의료 적응이 linear decodability를 일관되게 개선하지 않았다.

**수행한 Task**
- PATH-VQA, SLAKE, VQA-RAD에서 동결 VLM 표현 probing 및 prompting·의료 VLM·agentic 시스템과 비교
- 모델 크기별 probing 대 prompting 격차 분석
- 일반/의료 VLM 14쌍의 linear decodability 비교
- 생성의 answer-position bias(최대 10%p) 측정 및 probe의 위치 편향과 대조
- rejection sampling scoring으로 open-ended 설정 확장

### 8. Can Activation Steering Capture Multidimensional Authorship Style?
`arXiv:2609.04792` · [링크](https://arxiv.org/abs/2609.04792) · 관련도 32.0

**어떤 문제를 풀려는가** — 정의가 잘 되는 속성에서만 통하던 activation steering이 다차원적이고 규정이 어려운 authorship style도 다룰 수 있는지.

**무엇을 처음 한 논문인가** — 수사학적으로 구분한 aspect별 contrastive direction을 간섭을 고려해 합치는 training-free 프레임워크 A3S를 제시했다.

**Contribution**
- style을 다루려면 보통 자연어 style descriptor나 전용 학습이 필요했다 — 구조화된 contrastive prompting으로 activation space에 직접 style 표현을 구성해 둘 다 우회했다.
- 여러 방향을 단순 평균하면 성능이 무너진다 — 방향들이 공통 authorship backbone을 공유하면서 aspect별 residual에서 충돌한다는 진단으로 naive aggregation 실패를 설명하고, interference-aware aggregation으로 대체했다.
- 고정 steering 강도는 입력마다 다른 style 강도를 못 맞춘다 — instance 단위로 강도를 조정했다.

**수행한 Task**
- aspect별 contrastive direction 구성 및 backbone/residual 구조 분석
